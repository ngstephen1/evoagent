## Implementation Summary

The submitted system implements the full EvoAgent loop:

- Stage 0: zero-shot sandbox prediction.
- Stage 1: evaluation loop and token budget tracking.
- Stage 2: structured self-reflection over failed examples.
- Stage 3: strategy proposal with DSL validation and dynamic examples.
- Stage 4: iterative evolution harness, parent selection, smoke testing, and
  proof generation.

The final Kaggle result was produced after Phase 3 extensions:

- self-consistency inference with Qwen-family models,
- deterministic ensemble voting,
- LoRA fine-tuning,
- rejection sampling / STaR training.

## Reproducibility

The latest final valid candidate commands are documented in:

```text
steps_and_reproducibility.md
```

The packaged milestone/source-code workflow is documented in:

```text
source_code/run_instructions.md
```

Core local setup:

```bash
cd source_code
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

The final valid FT+RS/STaR submission can be reproduced from the original
Assignment 03 repository pipeline with:

```bash
modal run --detach run_modal.py::rejection_sample \
  --model /runs/lora_merged_qwen3_8b --k 8 --temp 0.8

modal run --detach run_modal.py::finetune \
  --base-model Qwen/Qwen3-8B --epochs 2 --tag qwen3_8b_rs \
  --train-file /runs/rs/train_sft_combined.jsonl

modal run --detach run_modal.py::predict \
  --model /runs/lora_merged_qwen3_8b_rs --sc-k 1 --tag ft-qwen3-8b-rs \
  --strategy-path strategies/ft_strategy.json

python3 phase3_dev_eval.py \
  --pred predict_out/ft-qwen3-8b-rs_dev_details.json \
  --mode program
```

API keys, Hugging Face tokens, Kaggle tokens, model weights, caches, and private
environment files are intentionally excluded from this submission package.
